# Project Brief — KFC Fried Chicken Landing Page

## Mục tiêu
Xây dựng một landing page quảng cáo gà rán theo phong cách thương hiệu KFC, dùng cho mục đích học tập/demo Vibe Coding và Antigravity.

> Lưu ý: Đây là project demo/học tập. Không sử dụng logo, hình ảnh, font hoặc tài sản thương hiệu KFC có bản quyền nếu chưa có quyền sử dụng.

## Công nghệ bắt buộc
- HTML5
- CSS3
- JavaScript thuần (ES6+)
- CSV làm nguồn dữ liệu
- Không dùng backend
- Không dùng PHP, Python server, Node.js server, API server hoặc framework frontend.
- Có thể dùng CDN cho thư viện frontend nếu thực sự cần, nhưng ưu tiên HTML/CSS/JavaScript thuần.

## Nguyên tắc
1. Mobile-first.
2. CTA rõ ràng.
3. Nội dung ngắn, dễ quét.
4. Sản phẩm được render từ CSV bằng JavaScript.
5. Không hard-code danh sách sản phẩm trong HTML.
6. Không tạo backend.
7. Code dễ đọc để người mới học Vibe Coding có thể hiểu và chỉnh sửa.
